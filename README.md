# Exam_Simulator

Программа реализует симуляцию экзамена для студентов

# Что тут происходит?

### Во время работы программа поддерживает в консоли актуальную информацию об экзамене, а именно выводит:

- Таблицу студентов из двух столбцов: «Студент», «Статус» (статус один из трех: «Очередь», «Сдал», «Провалил»).

- Таблицу отсортированную по статусу, чтобы в начале были студенты в очереди, затем - сдавшие, в конце - провалившие.

- Таблицу экзаменаторов из пяти столбцов: «Экзаменатор», «Текущий студент», «Всего студентов», «Завалил», «Время работы».

- Когда экзаменатор обедает или закончил принимать, в столбец «Текущий студент» выводит «-».

- Отдельной строкой количество оставшихся в очереди студентов из общего числа.

- Отдельной строкой время с момента начала экзамена.

- Поддерживает актуальную информацию и обновляет экран на месте.

### В конце работы программы выводит итоговую таблицу с результатами экзамена:

- Таблицу студентов из двух столбцов: «Студент», «Статус» (статус один из двух: «Сдал», «Провалил»).

- Таблицу отсортировывает по статусу, чтобы в начале были студенты, сдавшие экзамен, в конце - провалившие.

- Таблицу экзаменаторов из четырех столбцов: «Экзаменатор», «Всего студентов», «Завалил», «Время работы».

- Отдельной строкой время с момента начала экзамена и до момента и его завершения.

- Отдельной строкой имена лучших студентов через запятую (студент считается лучшим, если смог быстрее других сдать экзамен).

- Отдельной строкой имена лучших экзаменаторов через запятую (экзаменатор считается лучшим, если процент заваленных студентов у него ниже, чем у других экзаменаторов).

- Отдельной строкой имена студентов, которых после экзамена отчислят (исключат тех, кто провалил экзамен, закончив раньше других проваливших).

- Отдельной строкой лучшие вопросы через запятую (вопрос считается лучшим, если на него верно ответило больше всего студентов).

- Отдельной строкой вывод, удался экзамен или нет (экзамен удался, если сдало больше 85% студентов).
